\# TruthTrace \- Project Statement

\#\# 1\. Problem Statement

Crime investigation often requires collecting information from different sources, examining evidence, comparing suspect statements, and connecting events in the correct sequence. For beginners, understanding this investigation and logical deduction process can be difficult when it is presented only through theoretical examples.

TruthTrace is a Java-based digital crime investigation and logical deduction system designed to provide an interactive way to investigate fictional cases. The system allows users to examine case information, investigate locations, review evidence, study suspect statements, analyze the timeline, and make a final deduction based on the available information.

The project demonstrates how Java programming and object-oriented concepts can be applied to create a structured investigation system with multiple interacting components.

\---

\#\# 2\. Scope of the Project

The scope of TruthTrace includes:

\- Providing multiple fictional crime investigation cases.  
\- Allowing users to view case details and investigation information.  
\- Presenting different suspects, locations, evidence, and statements.  
\- Allowing users to examine and analyze available evidence.  
\- Providing a chronological timeline of important events.  
\- Supporting comparison of suspect statements and investigation clues.  
\- Allowing the investigator to make a final deduction.  
\- Providing a final result based on the submitted deduction.  
\- Providing a graphical user interface for a more interactive investigation experience.  
\- Maintaining a modular Java-based structure so that additional cases and features can be added in the future.

The current project focuses on fictional investigation scenarios and logical deduction rather than real-world crime investigation.

\---

\#\# 3\. Target Users

TruthTrace is intended for:

\- Students learning Java and Object-Oriented Programming.  
\- Beginners interested in logical deduction and problem-solving.  
\- Users who enjoy interactive investigation and detective-style applications.  
\- Students who want to explore how programming concepts can be applied to an interactive software project.

\---

\#\# 4\. High-Level Features

\#\#\# Case Management  
\- Multiple investigation cases.  
\- Case selection and case loading.  
\- Case-specific suspects, evidence, locations, and timelines.

\#\#\# Evidence Investigation  
\- View available evidence.  
\- Examine evidence related to the case.  
\- Connect evidence with other investigation information.

\#\#\# Suspect Investigation  
\- View suspect information.  
\- Review suspect statements.  
\- Interview suspects using case-specific questions.

\#\#\# Location Investigation  
\- Explore important locations related to the case.  
\- Review information associated with different investigation areas.

\#\#\# Timeline Analysis  
\- View important events in chronological order.  
\- Use the timeline to understand the sequence of events.

\#\#\# Logical Deduction  
\- Analyze evidence and suspect information.  
\- Compare clues and statements.  
\- Submit a final accusation.  
\- Receive the final investigation result.

\#\#\# Graphical User Interface  
\- Interactive case selection.  
\- Investigation dashboard.  
\- Dedicated sections for suspects, evidence, locations, and timeline.  
\- Final deduction interface.  
\- Dark detective-style visual interface.

\---

\#\# 5\. Project Objective

The main objective of TruthTrace is to create an interactive Java application that combines programming, logical reasoning, and investigation-based problem solving.

The project applies Java concepts such as classes and objects, constructors, methods, collections, conditional statements, loops, exception handling, input validation, modular class design, and GUI development to create a complete investigation workflow.
