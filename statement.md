# TruthTrace - Project Statement

## 1. Problem Statement

Crime investigation requires information to be collected from different sources such as evidence, suspect statements, locations, and event timelines. TruthTrace is a Java-based digital crime investigation and logical deduction system designed to provide an interactive way to investigate fictional cases.

The system allows users to examine case information, investigate locations, review evidence, study suspect statements, analyze the timeline, and make a final deduction based on available information.

## 2. Scope of the Project

- Multiple fictional crime cases
- Case details and investigation information
- Suspect profiles and statements
- Investigation locations
- Evidence collection and examination
- Chronological timeline analysis
- Comparison of clues and statements
- Contradiction analysis
- Final deduction and case result
- Java Swing graphical user interface
- Modular Java class structure
- Input validation and error handling

The cases are fictional and intended for educational and entertainment purposes.

## 3. Target Users

- Students learning Java and Object-Oriented Programming
- Beginners interested in logical deduction and problem solving
- Users who enjoy interactive investigation applications
- Students demonstrating programming concepts through an academic project

## 4. High-Level Features

1. Case Management
2. Evidence Investigation
3. Suspect Investigation
4. Location Investigation
5. Timeline Analysis
6. Logical Deduction
7. Graphical User Interface

## 5. Project Objective

The objective of TruthTrace is to create an interactive Java application that combines programming, logical reasoning, and investigation problem solving.

The project applies classes and objects, constructors, methods, encapsulation, collections, conditionals, loops, strings, exception handling, input validation, modular class design, and Java Swing GUI development.
